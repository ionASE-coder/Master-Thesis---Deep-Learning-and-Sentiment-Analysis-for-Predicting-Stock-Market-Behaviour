##This is the full pipeline of the script behind the Master Thesis "Deep Learning and Sentiment Analysis for Predicting Stock Market Behaviour" by Marc-Eduard Ionescu with coordinator professor Prof. Univ. Dr. Daniel Traian Pele.

#How to navigate the file?

The file was intended create the possibility of replicating the results.
The order in which to eexecute the python scripts is indicated by the 01, 02 numbers before each file. Files starting with a number and followed by the ipynb file are the executable files that create the pipeline.

In order to adjust the data base, please edit the excel file containing the links.

It is advised to use GPU for generating embeddings, sentiment and when employing HuggingFace models.

#Attention: PLease use your own API keey in the 01.ipynb_YT_CommentsAPI.ipynb file in order to acces the YouTube V3 API.
